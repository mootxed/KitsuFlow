# Сопоставление статусов и приоритетов

| UI            | GitHub state | Системная label                     |
| ------------- | ------------ | ----------------------------------- |
| Нужно сделать | open         | отсутствует status label            |
| В работе      | open         | `km:status:in-progress`             |
| Готово        | closed       | label не определяет результат       |
| Отложено      | open         | `km:status:postponed`               |
| Под вопросом  | нет Issue    | локальная запись, label отсутствует |

Закрытый Issue всегда «Готово». Открытый Issue без status label считается «Нужно сделать» и не изменяется автоматически.

Приоритеты: `km:priority:low`, `km:priority:medium`, `km:priority:high`, `km:priority:urgent`; отсутствие label означает «Без приоритета». Они допустимы только у GitHub Issues.

Если одновременно обнаружено несколько системных status или priority labels, сущность получает `conflict`; интерфейс показывает предупреждение и не удаляет labels молча. Технические labels с префиксом `km:` скрываются из обычного списка labels.
