# Сопоставление статусов и приоритетов

| UI            | GitHub state | Системная label                     |
| ------------- | ------------ | ----------------------------------- |
| Нужно сделать | open         | отсутствует status label            |
| В работе      | open         | `kf:status:in-progress`             |
| Готово        | closed       | label не определяет результат       |
| Отложено      | open         | `kf:status:postponed`               |
| Под вопросом  | нет Issue    | локальная запись, label отсутствует |

Новые системные labels создаются с префиксом `kf:`. Сохранена совместимость со старыми labels `km:*`: они распознаются при чтении, а при следующем изменении статуса или приоритета удаляются и заменяются на новые `kf:*`.

Закрытый Issue всегда «Готово». Открытый Issue без status label считается «Нужно сделать» и не изменяется автоматически.

Приоритеты: `kf:priority:low`, `kf:priority:medium`, `kf:priority:high`, `kf:priority:urgent`; отсутствие label означает «Без приоритета». Они допустимы только у GitHub Issues.

При переносе Issue в другую колонку статус и приоритет обновляются одной атомарной операцией (`moveIssue`), избегая состояния гонки между вызовами.

Если одновременно обнаружено несколько системных status или priority labels, сущность получает `conflict`; интерфейс показывает предупреждение и не удаляет labels молча. Системные labels с префиксами `kf:` и `km:` скрываются из обычного списка labels.
