# Design Reference Documentation

This directory contains design reference specifications and exported prototype HTML for the KitsuFlow pastel visual system.

> [!NOTE]
> These documents are for visual reference and documentation only.
> The production application entry point is `index.html` → `src/main.tsx` → React App.

## Files

- `reference.html`: Exported static HTML visual reference.
- `brand-spec.md`: Color tokens, typography, and visual specification.
- `DESIGN-HANDOFF.md`: Implementation handoff guidelines.
- `DESIGN-MANIFEST.json`: Open design manifest details.
